# UI仕様

## 共通

- API操作中は該当操作を連続実行できないようにする
- APIエラーは画面内に表示する
- データ更新後は画面を再読み込みせず、該当表示を更新する

## アイテム追加

- 未完了アイテム一覧の右上に追加ボタンを表示する
- 追加ボタンは `+` アイコンのみで表示し、ホバー時に「アイテムを追加」のツールチップを表示する
- 追加ボタンを押すとモーダルを開く
- モーダルには商品名、数量、キャンセル、追加を表示する
- 商品名を必須とし、モーダルを開いた直後に商品名入力欄へフォーカスする
- `Esc`、背景クリック、キャンセルでモーダルを閉じる
- 追加成功時はモーダルを閉じ、未完了一覧を更新する
- 追加失敗時はモーダルを閉じず、エラーをフォーム内に表示する

## リストサイドバー

- リスト一覧とリスト作成は同一のサイドバーに置く
- 幅が768px以上では、サイドバーを常に表示する
- 幅が767px以下では、初期状態でサイドバーを閉じる
- SPではヘッダーのメニューボタンから開閉する
- SPでリストを選択したらサイドバーを閉じる
- 開いている間は背景操作をできないようにする
- `Esc`で閉じる

## 前回のリスト

- ユーザーごとに最後に開いたリストIDをブラウザの`localStorage`へ保存する
- ログイン後、保存済みのリストIDが現在も所属リストに存在すればそのリストを開く
- 保存済みのリストが存在しない、または所属から外れている場合は、更新日時が最も新しいリストを開く
- リストが0件の場合はリスト作成を促す空状態を表示する
