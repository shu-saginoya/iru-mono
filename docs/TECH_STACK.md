# 技術構成書

## 概要

IRU-MONO の技術スタックおよび構成についてのドキュメントです。
低コスト、シンプル、スケーラブルな設計を重視しています。

## 推奨技術スタック

### フロントエンド

| 項目 | 選定技術 | バージョン | 理由 |
|------|---------|-----------|------|
| **フレームワーク** | React | 18+ | スマートフォン対応が簡単、開発効率が高い |
| **言語** | TypeScript | 4.9+ | 型安全性、開発効率向上 |
| **UI/CSS** | Tailwind CSS | 3+ | レスポンシブデザイン実装が簡単 |
| **状態管理** | Zustand または Redux | - | シンプルな状態管理 |
| **HTTP クライアント** | Axios | 1.0+ | API 通信の簡潔な実装 |
| **リアルタイム通信** | Socket.io クライアント | 4+ | リアルタイム同期対応 |
| **ホスティング** | Vercel | - | 無料、自動デプロイ、高速 |

### バックエンド

| 項目 | 選定技術 | バージョン | 理由 |
|------|---------|-----------|------|
| **ランタイム** | Node.js | 18+ | JavaScript/TypeScript で統一 |
| **フレームワーク** | Express | 4.18+ | シンプルで軽量、API 構築に最適 |
| **言語** | TypeScript | 4.9+ | 型安全性、保守性向上 |
| **認証** | JWT (jsonwebtoken) | 9+ | シンプルで安全 |
| **パスワード暗号化** | bcrypt | 5+ | 業界標準 |
| **リアルタイム通信** | Socket.io | 4+ | WebSocket 対応、フォールバック機能 |
| **ロギング** | Winston または pino | - | 本番環境対応 |
| **ホスティング** | Railway | - | 無料～低コスト、自動デプロイ |

### データベース

| 項目 | 選定技術 | 理由 |
|------|---------|------|
| **DBMS** | PostgreSQL | リレーショナル、安定性、無料ホスティング対応 |

| **ホスティング** | Railway | PostgreSQL 無料プラン対応 |

| 項目 | 選定技術 | 理由 |

## 認証フロー

```
1. ユーザーがログイン画面でユーザー名/パスワードを入力
2. バックエンドで bcrypt でパスワードを検証
3. 検証成功時、JWT トークンを発行
4. クライアントが JWT を localStorage に保存
5. 以降、API リクエストに Authorization ヘッダーで JWT を送付
6. バックエンドで JWT を検証してリクエスト処理
```

## 代替案：Firebase + Flutter

もし **さらにシンプル** にしたい場合の代替案：

| 項目 | 選定技術 |
|------|---------|
| **フロントエンド** | Flutter (Web + Mobile) |
| **バックエンド** | Firebase Realtime Database |
| **認証** | Firebase Authentication |
| **ホスティング** | Firebase Hosting |
| **コスト** | 無料～¥1,000/月 |

**メリット**:
- バックエンド実装が不要（Firebase で全て対応）
- オフライン対応が簡単
- 更にシンプル

**デメリット**:
- Firebase のベンダーロックイン
- カスタマイズの自由度が低い

## 開発環境セットアップ

### 前提条件

- Node.js 18+ / npm または yarn
- PostgreSQL ローカルインスタンス（開発環境）
- Git

### ローカル実行コマンド（予定）

```bash
# リポジトリクローン
git clone https://github.com/shu-saginoya/iru-mono.git
cd iru-mono

# 依存パッケージをインストール
npm install

# データベース マイグレーション
npm run db:migrate

# ローカル開発サーバー起動
npm run dev

# テスト実行
npm run test
```

## セキュリティ対策

| 対策 | 実装方法 |
|------|---------|
| **HTTPS** | Vercel / Railway で自動対応 |
| **パスワード暗号化** | bcrypt で hash 化、平文保存なし |
| **JWT トークン** | 署名付き、有効期限設定 |
| **CORS設定** | オリジン限定（フロントエンド URL のみ） |
| **入力検証** | バリデーションライブラリ（Zod など） |
| **SQL インジェクション対策** | Prisma ORM で自動対応 |
